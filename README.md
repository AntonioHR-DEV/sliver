# 🏃 Sliver

A tight, precision-focused 2D platformer built in Unity 6. Navigate increasingly challenging rooms filled with spike hazards, moving platforms, and wall jump puzzles. Death is instant — respawn is instant. The loop is: die, learn, conquer.

## Features

- Custom Rigidbody2D character controller — velocity-driven, not AddForce
- Coyote time — jump grace period after walking off a ledge
- Jump buffering — input registered slightly before landing
- Variable jump height — tap for short jump, hold for full height
- Wall slide and wall jump
- Fast fall
- Double jump
- Full animation state machine with Pixel Adventure sprites
- Cinemachine camera with screen shake on death
- Parallax background scrolling
- Spike hazards, moving platforms, and checkpoints
- 10 levels with progressive difficulty
- Star rating system based on completion time

## Controls

| Action | Keyboard | 
|---|---|
